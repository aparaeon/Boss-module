# Requirements
- Each file must have an `app.py` and a function `main` declared within it 
- All scripts must be placed in its own directory
- Must place the data into result/<type>/<server>/<path>
  - `type` can be either: `cobblemon` or `pixelmon`
  - `server` can be any of: `proxy` or `spawn` or `realms` or `wild` or `gyms`
  - the `path` needs to be the exact path in the server, for example: `world/region/0/0/0.dat` or `world/region/0/0/0.mca`
